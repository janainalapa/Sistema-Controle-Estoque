# Sistema de Controle de Estoque

## Sobre o projeto

Projeto desenvolvido durante a graduação em Análise e Desenvolvimento de Sistemas com o objetivo de criar uma solução para gerenciamento e controle de estoque.

O sistema permite organizar informações de produtos, acompanhar quantidades disponíveis e facilitar o controle dos itens cadastrados.

## Objetivos

- Desenvolver uma aplicação para controle de estoque;
- Melhorar a organização das informações de produtos;
- Facilitar o acompanhamento de entradas e saídas;
- Aplicar conhecimentos adquiridos durante o curso.

## Tecnologias utilizadas

- AppSheet (desenvolvimento do aplicativo);
- Google Sheets (armazenamento e gerenciamento dos dados);
- Ferramentas Google Workspace para documentação do projeto.

## Funcionalidades

- Cadastro de produtos;
- Consulta de itens cadastrados;
- Controle de quantidade em estoque;
- Organização das informações dos produtos.
